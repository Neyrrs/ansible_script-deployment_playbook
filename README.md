# Trend Vision One Windows Agent Deployment

This Ansible playbook installs the Trend Vision One agent on Windows hosts.

The playbook uses the PowerShell deployment script from:

```text
group_vars/deployment_script.ps1
```

Ansible copies this script to the Windows managed node, runs it as Administrator, and removes it after the run.

## Requirements

- Ansible
- WinRM enabled on the Windows host
- Ansible collection `ansible.windows`
- A Windows account with Administrator rights
- Internet access from the Windows host to Trend Micro

Install the required collection:

```bash
ansible-galaxy collection install -r requirements.yml
```

## Configure the inventory

Edit `inventory/hosts.ini` and add your Windows host:

```ini
[vision_one_windows]
windows-home ansible_host=DESKTOP-PI6EBAV

[vision_one_windows:vars]
ansible_user=Administrator
ansible_connection=winrm
ansible_winrm_transport=ntlm
ansible_port=5985
ansible_winrm_scheme=http
```

Do not store `ansible_password` in a plain text file. Use Ansible Vault or provide it with a secure secret-management method.

## Configure the deployment script

The file `group_vars/deployment_script.ps1` is generated by the Trend Vision One console. It contains the tenant information and activation token.

Keep this file private. Do not commit it to a public repository.

The source and destination paths are configured in:

```text
group_vars/vision_one_windows.yml
```

Default values:

```yaml
vision_one_script_src: "{{ playbook_dir }}/group_vars/deployment_script.ps1"
vision_one_script_dest: "C:\\Windows\\Temp\\deployment_script.ps1"
```

If the Windows host uses a proxy, set:

```yaml
vision_one_use_proxy: true
vision_one_proxy_url: "http://proxy.example.local:3128"
```

The proxy setting is used by Ansible when needed. The deployment script also has its own proxy variables, so configure both places if the script requires a proxy for Trend Micro downloads.

## Run the playbook

Run the playbook from this directory:

```bash
ansible-playbook -i inventory/hosts.ini playbook.yml
```

If you use encrypted Ansible Vault variables, add:

```bash
ansible-playbook -i inventory/hosts.ini playbook.yml --ask-vault-pass
```

## What the playbook does

1. Checks whether the `tmlisten` and `ntrtscan` services are already running.
2. Skips installation when both services are already running.
3. Copies `deployment_script.ps1` to the Windows host.
4. Runs the script with PowerShell.
5. Shows the script output.
6. Removes the copied script, even when the installation fails.
7. Checks the services again after installation.

The PowerShell script downloads the Trend Micro installer, installs the agent, activates it, and checks the agent registration.

## Troubleshooting

- Check the Ansible output for WinRM connection errors.
- Make sure the Ansible user has Administrator rights.
- Make sure the Windows host can access Trend Micro endpoints.
- Check the Trend Micro log at:

```text
%APPDATA%\Trend Micro\V1ES\v1es_install.log
```

- Check the `EndpointBasecamp.log` file if agent registration fails.
